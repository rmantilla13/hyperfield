# Sample media

Every picture and clip in this repository was generated by OpenField itself, on
open-weights models running on one local RTX 5090. No real people, no
third-party footage, no stock media. The faces in the samples are generated.

This file lists every shipped media file with the take that made it, the
prompt, the seed and the model, as far as they can be recovered. Take ids belong
to the development database the file was rendered in. The prompt, seed, model
and size carry over to any install, and every app's graph is in
[`workflows/`](../workflows).
